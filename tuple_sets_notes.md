## Tuple

A tuple is a built-in data type that allows you to create immutable sequences of values.

The values or items in a tuple can be of any type. This makes tuples pretty useful in those situations where you need to store heterogeneous data, like that in a database record.

Values of a tuple are syntactically separated by commas. Although it is not necessary, it is more common to define a tuple by closing the sequence of values in parentheses.

Tuples are:

=> Ordered - They maintain the order of elements.
=> Immutable - They cannot be changed after creation.
=> Allow duplicates - They can contain duplicate values.

## Set

A Set in Python programming is an unordered collection data type that is iterable, mutable and has no duplicate elements. \

Set are represented by { } (values enclosed in curly braces)
